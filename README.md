# AI Zero to Agent

**A structured, hands-on learning path from complete Python beginner to building autonomous AI agents.**

No fluff. No theory-first lectures. You build something every single day.

---

## Who Is This For?

- You've never written Python (or it's been years)
- You're curious about AI agents but don't know where to start
- You learn best by building, not watching
- You want a clear, day-by-day path with no ambiguity

---

## The Path

```
Week 1–2   Python → API calls → Claude → Tool Use → Agent Loop
Week 3–4   RAG (answer questions from your own documents)
Week 5–6   Agentic patterns (planning, error recovery, multi-step)
Week 7–8   MCP (Model Context Protocol — standard tool interface)
```

## How It Works

Each week contains a **day-by-day checklist**. The rules are simple:

1. **One day at a time** — don't move forward until every box is checked
2. **Build first, read second** — always write code before reading docs
3. **Solve real problems** — by Day 13, you're building something for yourself

Every day ends with a clear "done when" statement so you know exactly when to move on.

---

## What You'll Build (Weeks 1–2)

By the end of the first two weeks, you'll have built:

- A tip calculator and unit converter (Day 2)
- A number guessing game (Day 3)
- A persistent contact book that saves to disk (Days 4–5)
- A weather fetcher using a real API (Day 6)
- A terminal chatbot with memory (Day 10)
- An AI agent that decides which tools to call and chains them together (Day 12)
- Something that solves a real problem *you* have (Day 13)

## Philosophy

> The best way to learn AI is to build with it — not to read about it.

This curriculum is designed around three beliefs:

1. **Projects over theory** — You understand concepts by using them, not memorizing them
2. **Compounding skills** — Each day builds directly on the previous one
3. **Real utility** — By week 2, you're building tools you'll actually use
